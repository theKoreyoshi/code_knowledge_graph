# 泛化能力验证报告

对形态完全不同的工程执行同一套**零配置**流程（`build_from_path`，等价于
`python -m ckg build <path>`），然后对结果做断言。

用例 01-03 使用仓库自带示例，04-05 由脚本在运行时生成，因此在任何机器上都能复现：

```bash
python tools/validate.py
```
